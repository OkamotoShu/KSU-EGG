# AR体験版

## 使い方

1. `/about` の「ARでたまごに会おう」、または `/ar` を開く。
2. `/ar/card.png` を別の画面に表示するか印刷する。
3. HTTPSのURLをスマートフォンで開き「カメラをはじめる」を押す。
4. カメラを許可し、カード全体を映す。認識するとピンクのたまごが表示される。
   たまごをタップすると軽く揺れ、周りに星が現れる。連打はアニメーション終了まで無視する。
5. 「終了」でカメラを停止する。ページ移動・バックグラウンド移行でも停止する。

PCでは `http://localhost:3000/ar` も利用可能。スマートフォンからPCの
LAN IPをHTTPで開く方法ではカメラが利用できないため、HTTPSを使用する。

## 素材と構成

- ユーザー提供の `public/ar/card.png` と `targets.mind` を使用する。
- `targets.mind` の先頭のターゲットを追跡する。
- 表示素材は `public/egg_1_1.png`。3Dモデルではなく平面の画像。
- 登録済みプレイヤーは回答配列の2番目（巣の選択）でキャラクターを決める。
  `1: koyamachan`（たまごの周囲を一周）、`2: musubukun`（抱きしめてハート）、
  `3: yamachan`（帽子として着地し、魔法陣で浮かせる）。未登録・未選択時は1番を使う。
- yamachanの最初の魔法後は、帽子と星形の魔法印をARセッション中保持する。
- たまごのタップ時にWeb Audio APIで短い効果音を端末内生成する。
- 多人の場合はカメラ起動前に表示するプレイヤーを選ぶ。
- 認証・Firestore・ゲーム進行は変更しない。
- カメラ映像は端末内で処理し、アップロードしない。
- MindAR 1.2.5 / Three.js 0.160.0 は `public/ar/vendor` から配信する。
- カードを差し替えるときは、同じ画像から `.mind` も再生成する。

## 実機チェック

- iPhone Safari / Android Chromeで許可・拒否・再試行を確認。
- カードを近づける／傾ける／画面外に出す操作で表示と非表示を確認。
- 終了・ページ移動・バックグラウンド移行後のカメラ停止を確認。
- たまご・透明な余白・背景をそれぞれタップし、たまごだけが反応することを確認。
- アニメーション中にカードを外し、再認識時に姿勢が元に戻っていることを確認。
- 現在のカードは輪郭が滑らかで特徴が少ないため、認識しづらい場合は
  文字や模様などの細部があるカードで再コンパイルする。

同梱カードとターゲットの対応・実際の追跡品質は実機で確認が必要。

操作判定の自動テスト: `node --test tests/ar-interaction.test.mjs tests/ar-character-action.test.mjs`
